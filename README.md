# 単語帳

毎日つづけやすい、ゲーム感覚の単語帳アプリ（スマホ向け）。

**アプリを開く：https://normal-megante.github.io/vocabulary/**

- 英単語・用語・漢字など、覚えたいものを自分で登録して使います（単語のデータはアプリに入っていません）。
- Excel や Google スプレッドシートの「表・裏・例文・メモ」の4列を、コピーして貼り付けるだけでまとめて登録できます。
- めくって自己採点。覚えた単語はたまに、苦手な単語はよく出てきます（間隔反復）。
- データはスマホの中だけに保存されます（サーバーには送りません）。ときどき設定画面から「バックアップを保存」してください。
- Android の Chrome で開き、メニューの「ホーム画面に追加」で、アプリのように使えます。ネットにつながっていなくても開けます。

## 開発

HTML / CSS / JavaScript だけで作っています（ビルド作業なし）。

- PC で確認：このフォルダで `python dev-server.py` → http://localhost:8130
- テスト：このフォルダで `node --test`
